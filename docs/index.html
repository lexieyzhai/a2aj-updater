A2AJ Update Checker

Check for new RPD/RLLR cases and push updates to Google Drive.

Run an update check

This button triggers the GitHub Actions workflow. If there is a new dataset snapshot, it will download, filter RPD/RLLR, and upload new files to Drive. If nothing new, it will say so in the workflow logs.

View workflow runs

Tip: You must be logged into GitHub for the button to work.

Where the files go

New uploads land in your Google Drive folder (inside an A2AJ_updates subfolder) with a timestamped run folder and zipped RPD/RLLR files.

You can share this page with others so they can click the button for you.

If you need help, check the README in the repo for setup steps.
