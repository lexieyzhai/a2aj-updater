Rules

Classic-style UNO flow with number cards, skips, reverses, draw twos, wilds, and wild draw fours. Draws stack only through the card effect itself. No challenge rule for wild draw four.

The host tab keeps the match alive. If the host leaves, everyone should rejoin a fresh room.
